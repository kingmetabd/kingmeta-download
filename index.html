Quick Setup

  1. Open the GitHub Releases page and download the intended KingMeta installer.
  2. Run the installer on a compatible Windows 10 or Windows 11 PC.
  3. Launch KingMeta and complete any required trial, activation, or API-key setup.
  4. Use metadata and prompt tools as needed; click 4K UPSCALER to open the local video/image upscaler.

Before You Start

  • Gemini-backed features require a valid API key and internet connectivity.
  • The local upscaler opens in your browser through a service running on your own PC; it is not a public website server.
  • Large video files and high-resolution image batches may take substantial time and disk space.
  • For EPS/AI preview or rendering functions that rely on Ghostscript, install Ghostscript separately.

Frequently Asked Questions

What is KingMeta?

KingMeta is a Windows desktop toolkit for microstock contributors and designers. It combines metadata generation and CSV export with prompt creation, an in-app Gemini chat assistant, and video/image upscaling tools.

Does the Gemini chatbot work offline?

No. The chat interface is built into KingMeta and runs on the desktop, but Gemini replies are generated through the Gemini API. A configured API key and internet connection are required.

Is image upscaling powered by Real-ESRGAN?

The current image-batch workflow uses Lanczos resizing plus color, contrast, sharpening, and optional denoise enhancements. Do not treat it as AI model-based reconstruction.

Can I upscale videos to 4K?

The video tool offers selectable output heights including 2160p (4K) and 4320p (8K), with FFmpeg-based resizing and quality controls. Output quality depends on the source video and selected settings; enlarging a video does not recover detail that was never present.

Which file types does KingMeta support?

The metadata workflow supports vector/design assets such as EPS, AI, SVG, and PSD, along with supported photo and video formats. The upscaler has its own supported image and video file selections.
