Application Preview
AI and connectivity: Metadata generation, prompt generation, and Gemini chat require a configured Gemini API key and internet access. The Upscaler interface runs locally on the user's PC. Video processing uses FFmpeg; image upscaling in the current build uses Lanczos resizing and image enhancement rather than Real-ESRGAN model-based reconstruction. Quick Setup

  1. Open the GitHub Releases page and download the version you intend to install.
  2. Run the installer on a compatible Windows 10 or Windows 11 PC.
  3. Launch KingMeta and complete any required trial, activation, and API-key setup.
  4. Use the metadata and prompt tools as needed; click 4K UPSCALER to open the local video and image upscaler.

Before You Start

  • Gemini-backed features require a valid API key and internet connectivity.
  • The upscaler runs locally on your PC; 127.0.0.1:5000 is a local address, not a public website.
  • Large video files and high-resolution image batches may take substantial time and disk space.
  • Install Ghostscript separately for EPS/AI preview or rendering functions that rely on it.

Frequently Asked Questions

What is KingMeta?

KingMeta is a Windows desktop toolkit for microstock contributors and designers. It combines metadata generation and CSV export with prompt creation, an in-app Gemini-backed chat assistant, and video and image upscaling tools.

Does the Gemini chatbot work offline?

No. The chat interface is integrated into KingMeta, but Gemini responses are generated through the Gemini API. A configured API key and internet connection are required.

Is image upscaling powered by Real-ESRGAN?

The current image-batch workflow uses Lanczos resizing with color, contrast, sharpening, and optional denoise enhancements. It does not use Real-ESRGAN AI reconstruction.

Can I upscale videos to 4K or 8K?

The video tool offers output heights including 2160p (4K) and 4320p (8K), with FFmpeg-based resizing and quality controls. Enlarging a video does not restore detail that was absent in the source.

Which file types does KingMeta support?

The metadata workflow supports vector and design assets such as EPS, AI, SVG, and PSD, along with supported photo and video formats. The upscaler has its own supported image and video file selections.
